BACKTESTER V2 MR

OBJETIVO
- Analiza TESTLOG JSON del BOT FIX14.x.
- Busca automáticamente combinaciones por mercado, dirección, timing, tramo de confianza y clasificación histórica.
- Exige una muestra mínima configurable para reducir conclusiones basadas en pocas operaciones.
- Resume timing y muestra los patrones históricos incluidos en el TESTLOG.
- NO conecta con Deriv y NO ejecuta operaciones.

USO
1. Publique estos archivos en el mismo repositorio BACKTESTER_V1_MR reemplazando los anteriores, o en un repositorio nuevo.
2. Abra index.html / GitHub Pages.
3. Cargue el TESTLOG JSON.
4. Deje muestra mínima 20 para la primera exploración.
5. Pulse BUSCAR MEJORES COMBINACIONES.
6. No interprete el porcentaje histórico como garantía futura.
